## 📖 项目简介

DESIGN.md 是 Google Stitch 提出的新概念:一份纯文本(Markdown)设计系统文档,AI 编码代理读取后即可生成风格一致的界面。本项目从真实网站中提取并分析了 73 份 DESIGN.md,覆盖 AI 平台、开发者工具、金融科技、电商、汽车等主流品牌——把其中任意一份放进项目根目录,告诉 AI"照这个风格做一个页面",就能得到有真实设计深度的 UI(配色令牌、字体层级、组件规则齐全),而不是表层模仿。

## ✨ 主要特性

- 收录 73 份 DESIGN.md,全部提取自 Claude、Vercel、Linear、Stripe、Airbnb、Apple、Tesla 等真实网站
- 基于 Google Stitch 的 DESIGN.md 规范,并做了章节扩展
- 覆盖视觉主题、调色板与语义色、字体规则、组件样式、布局原则、阴影层级等 9 大板块
- 每份文档附带"禁忌清单(Do's and Don'ts)"与响应式策略,防止 AI 生成反模式设计
- 内置 Agent 提示词指南与配色速查,拿到即可直接投喂 AI 编码代理
- 无需 Figma 导出、无 JSON Schema、无需特殊工具链——就是一个 Markdown 文件
- 附带 `preview.html` 预览页,可离线快速核对设计效果
- 持续更新,另设 90 年代复古网页(Retro Web)专题系列

## 🚀 快速开始

1. 打开原仓库的 Collection 章节,按分类挑选一个心仪的品牌设计(如 Linear、Stripe、Notion)。
2. 进入该品牌对应页面(或直接下载其 `DESIGN.md` 文件)。
3. 将 `DESIGN.md` 放到你项目的根目录:

```bash
cp DESIGN.md /path/to/your-project/DESIGN.md
```

4. 打开你常用的 AI 编码代理(Claude Code、Cursor、Copilot 等)或 Google Stitch。
5. 用一句话下发生成指令,例如:

```text
请阅读项目根目录的 DESIGN.md,按照其中的设计系统
做一个落地页,严格保持配色、字体与组件风格一致。
```

6. AI 会读取文档中的调色板、字体层级、组件样式与布局规则,生成视觉一致的页面。
7. 如需更精细控制,参考文档末尾的"Agent Prompt Guide"章节,直接套用现成提示词。
